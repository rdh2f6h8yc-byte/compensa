# Compensa

Simulador para jóvenes que quieren independizarse: compara irte de casa, compartir piso, vivir en pareja o comprar tu primer piso, y mira cómo queda tu dinero en 1, 5 y 10 años.

- Web estática (`index.html`), publicada en Vercel.
- Incluye la sección «Ayudas para jóvenes» (Bono Alquiler Joven, Aval ICO), revisada cada mes.
